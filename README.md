# The GOAT Debate - Messi vs Ronaldo

A neutral, source-labeled, interactive Next.js reference site for comparing Lionel Messi and Cristiano Ronaldo across statistics, trophies, records, tactical profiles, controversies, and legacy.

The site deliberately avoids declaring a simplistic winner. It shows exact stable figures where official sources are clear and labels volatile or provider-dependent metrics as reconciliation items.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

The app uses static export and is ready for GitHub Pages.
